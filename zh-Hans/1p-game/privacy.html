1P Game

隐私政策

最后更新：2026 年 11 月 1 日

简而言之：1P Game 不收集任何与你有关的个人信息。 没有账号，没有注册，也没有任何由我们运营的服务器会接收你的数据。 App 记住的所有内容都只留在你自己的设备上。

本政策以英文、法文与简体中文发布。英文版本为权威版本，译文仅供参考；如译文与英文原文有出入，以英文原文为准。

本政策适用于 iPhone 与 iPad 上的 1P Game 应用。1P Game 由 Funfinch（位于中国上海的个人独立开发者， 以下称“我们”）发布。本政策说明本 App 会如何处理信息，以及它刻意不做哪些事情。

1. 我们收集的信息

我们什么都不收集。具体而言，1P Game 不会收集或传输：

  • 你的姓名、电子邮箱、电话号码或通信地址；
  • 广告标识符（IDFA）或设备标识符（IDFV）；
  • 你的位置信息；
  • 你的通讯录、照片、相机、麦克风或健康数据；
  • 与你关联的使用分析、游戏统计数据或崩溃报告。

由于不收集任何个人数据，我们也没有任何个人数据可供出售、出租、共享或向第三方披露。 基于同样原因，在我们这一侧也不存在个人数据的跨境传输。

2. 存储在你设备上的信息

App 使用 Apple 的标准本地存储，在你的设备上保存游戏进度、已解锁内容与偏好设置。 这些信息不会离开你的设备，我们也无法看到。

删除 App 会清除这些数据。如果你的设备通过 iCloud 或电脑做过备份，该备份可能包含 App 的本地数据； 备份由你通过 Apple 的设置控制，而不是由我们控制。

3. 购买与订阅

1P Game 提供可选的按月订阅、按年订阅，以及一次付费的永久解锁。所有付款均由 Apple 通过 App Store 处理。 我们始终看不到你的姓名、账单地址、银行卡号或任何付款明细。

为了判断是否为你解锁内容，App 会校验 Apple 的 StoreKit 框架提供的签名交易凭证。 该校验在你的设备上完成。我们没有会存储你购买记录、或将其与身份关联的服务器。

Apple 对你购买行为的处理适用 Apple 自身的隐私政策： apple.com/legal/privacy。

4. 网络访问与游戏内容

1P Game 的每一款游戏都打包在 App 内并在本地运行。游戏界面不会从互联网加载内容， 游戏数据也不会传输到任何地方。App 完全可离线游玩。

网络访问只发生在两种情况，且都是向 Apple 发出请求：

  • 购买。 当你购买、恢复或续订订阅，以及 App 检查你已解锁哪些内容时， Apple 的 StoreKit 会连接 App Store。
  • 版本检查。 App 启动时会向 Apple 的公开查询服务 itunes.apple.com 询问 1P Game 是否有新版本，以便提示你更新。该请求只携带 App 的 bundle identifier 与你 App Store 的地区代码，不含姓名、邮箱、账号或广告标识符。

如同任何发往服务器的请求一样，Apple 可以看到请求来源的 IP 地址。这是互联网的工作方式； 我们从不接收、记录或保存它。

5. 第三方软件

App 不包含任何第三方广告、分析、归因或崩溃上报 SDK。不会向数据经纪商或广告网络共享任何数据。

6. 儿童隐私

1P Game 是面向一般用户的 App，不面向 13 岁以下儿童。我们不会有意收集任何人的个人信息，包括儿童。 如果你认为某位儿童向我们提供了个人信息，请联系我们，我们会据此处理——尽管实际上我们并不持有此类信息。

7. 你的隐私权利

GDPR、CCPA 等隐私法律赋予你访问、更正、导出或删除所持有个人数据的权利。 由于我们不持有你的任何个人数据，我们这一侧没有可供访问、更正、导出或删除的内容。

本地游戏数据可随时通过删除 App 从你的设备上清除。如需取消订阅，请使用你设备上的设置 （见支持页面）。你仍可就任何隐私问题联系我们，我们会予以回复。

8. 数据留存

我们不保留任何个人数据，因此没有留存期限可描述。App 本地存储的数据会一直保留， 直到你删除 App，或数据被你的设备或备份设置清除。

9. 本政策的变更

如果本政策发生变化，我们会更新本页面以及上方的“最后更新”日期。如果未来某个版本的 App 开始收集信息， 该变化会在生效前于本页说明，并在 App 的版本说明中标注。
